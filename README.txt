MICKLEHAM CHURCH WEBSITE — HOMEPAGE DEMO

Open index.html in a browser.

This is a front-end prototype for discussion with the church. It is intentionally self-contained and does not send real forms or take real donations.

Included:
- Warm responsive homepage
- Mobile navigation
- Service/calendar concept
- News and weekly announcements
- Gallery concept
- Contact form demonstration
- Donation call-to-action
- Volunteer-friendly CMS concept

Next development stage:
- Connect the service calendar to a CMS
- Add volunteer editing panel
- Add real news publishing
- Add real image gallery
- Connect contact forms
- Integrate a secure donation provider
- Add real church content and approved photographs
