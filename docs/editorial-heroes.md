## Westhumble decision

The existing page actually contains westhumble-placeholder.jpg, explicitly labelled as an illustrative generated image; it is not a genuine chapel photo. A genuine supplied photograph is available at assets/images/visit/westhumble-chapel.jpg, but only 300x199 and documented for uncropped display at no more than 300 CSS pixels (docs/visit-content-sources.md). The three genuine Eco Group working-party photographs are portrait 1200x1600 compositions focused on volunteers, supplies and a fragment of the chapel wall; a panoramic crop would lose the people and still not establish the building. Neither source supports a good seamless panoramic chapel hero. Therefore Westhumble gets the compact generic editorial treatment using supplied Image1, not a fictional replacement chapel portrait. Its existing meaningful content image/caption is unchanged. No new hero is represented as the actual Chapel.

## Shared architecture and presentation

editorial-hero-config.cjs is the single explicit opt-in/image/focal map. build-editorial-heroes.js decorates only those pages, keeps original content verbatim, is idempotent and reverses the decoration when a route is removed. npm build runs it after content/gallery generation; the established typography/cache hook runs last. site.js detects the generated class and loads the small editorial module instead of the generic header-photo stylesheet. Existing seamless hero code/CSS and ordinary header-photo stylesheet are untouched.

One decorative responsive img covers the existing navigation + content-sized title, avoiding duplicate crops/downloads. Static CSS reserves title layout before the image loads; decode only activates header transparency. Safe church-green fallback is visible on failure. Resize/scroll observers update only background coordinates and top-state surface, never copy/menu or header geometry. Print hides decoration.

Hero padding26px top/30px bottom desktop,24px/28px at<=900. Headings and leads stay within the protected62% region on wide layouts; narrow layouts use full width. Original typography/copy is retained. Long copy/title determines height, never an arbitrary fixed hero height. A phone-only wrapping adjustment to the existing long Sunday church-bells reference link removes its pre-existing320px overflow without changing its text/destination.

Overlay: RGB24,57,45. Wide left-to-right opacity92% at0,78% at40%,70% at65%,12% at100. Narrow92%,81% at65%,78% at100. Navigation plate90%, with a short10px tail below its measured boundary; no blur/filter, image duplication or long mask. Solid green returns on scroll.

Cache parameters: internal shared script headerPhoto20261024-4, editorial CSS/module20261024-1. The other44 internal public pages change only their shared script cache parameter; Home HTML is byte-identical.
