## Location presentation

No working lightweight two-marker implementation exists in this repository: the old visitor page had an artificial map placeholder. Use the requested fallback: two clear addresses, separate Google Maps searches and a Google Maps walking-directions URL containing both named destinations. No iframe, fake map, new map dependency or API key. External links use `target="_blank" rel="noopener noreferrer"` and announce new tabs to assistive technology.
